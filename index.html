💻 Tutorial PC

Ambil ID Discord

  • 01. Buka pengaturan (gear) di Discord PC.
  • 02. Pilih "Advanced" di sidebar.
  • 03. Aktifkan "Developer Mode".
  • 04. Klik kanan profil → Copy User ID.

📱 Tutorial Mobile

Ambil ID Discord

  • 01. Tap foto profil (kanan bawah).
  • 02. Masuk ke Settings (gear).
  • 03. Advanced → Developer Mode ON.
  • 04. Tap tiga titik di profil → Copy ID.
